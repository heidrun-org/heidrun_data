## 0. Introduction

This document gives one short definition for each official name of the project. The other words of the project are in [index.md](index.md).

## 1. Heidrun Organization

The whole project, on GitHub under the organization `heidrun-org`.

## 2. Heidrun Code

The application for coding agents. Its identifier is `heidrun_code`, and its repository is `heidrun-org/heidrun_code`. The packages of this repository come from its folder `packages/data_layers`.

## 3. Heidrun Data

The data layer of Heidrun Organization: the data layer packages and the command line tool heidrun_data. Its identifier is `heidrun_data`, and this repository holds it.

## 4. Heidrun Notebook

The application for project management and note taking. Its identifier is `heidrun_notebook`, and its repository is `heidrun-org/heidrun_notebook`.

## 5. The command line tool heidrun_data

The one command line tool of the package `packages/apps/heidrun_data`. It gives a coding agent the data of the four data layer packages in one SQLite file.

## 6. Official name and identifier

The official name is the name in a text for people, written with a space, for example "Heidrun Data". The identifier is the name in a repository name, a package name, or a folder name, written in lowercase with an underscore, for example `heidrun_data`.
