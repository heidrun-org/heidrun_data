# Glossary of heidrun_data

- Created: 25 October 2026
- Last updated: 25 October 2026
- Status: Maintained overview for people
- Related framing: [Project instructions](../../../AGENTS.md)
- Related issue: [issue 10](https://github.com/heidrun-org/heidrun_data/issues/10)

This folder holds the glossary of the repository heidrun_data: one short definition for each word that the project uses for one of its parts. Use these words, and no other word, in the code, in the documents, and in the conversations. One word means one thing, and one thing has one word.

The glossary is split by topic into small files. Read only the files that match the part that you change. The file `index.md` lists them.
