# Agent rules

- Created: 25 October 2026
- Last updated: 25 October 2026
- Status: Maintained overview for people
- Related framing: [Project instructions](../../AGENTS.md)
- Related issue: [issue 10](https://github.com/heidrun-org/heidrun_data/issues/10)

This folder holds the rules that every coding agent follows when it works on the repository heidrun_data.

Read the glossary first, because it defines the words that the other files use. The glossary is the folder `glossary`, split by topic: read only the files that match the part that you change. Then read the rule files that match the part that you change. The file `index.md` lists every file and every subfolder of this folder, and says when to read each file. No file of this folder is larger than the maximum size that the file `AGENTS.md` gives, and the command `pnpm --filter agents_rules_checker test` tests it.
